Three decisions hidden in the detail

01

Margin quality needs attention

520 products produced negative delivered gross profit. They represent — of delivered net sales, so revenue growth alone overstates product health.

Action: review pricing, discounting and unit economics at SKU level.
02

Fit is the largest return problem

Wrong size is the leading return reason and accounts for — of returned units.

Action: improve size guidance and product-page fit information.
03

Volume is not the same as value

Category scale differs materially from category margin. The most useful operating view combines sales, gross profit and return rate—not sales alone.

Action: prioritize categories on contribution, not only top-line volume.

orders["order_status"] = (
    orders["order_status"]
    .str.strip().str.lower()
)

order_items["net_value"] = (
    order_items["quantity"] * order_items["unit_price"]
    - order_items["discount_amount"]
)

sales = order_items.merge(
    orders,
    on="order_id",
    how="left",
    validate="many_to_one"
)
SELECT
    order_month,
    COUNT(*) AS total_orders,
    SUM(order_status = 'delivered') AS delivered_orders,
    ROUND(SUM(
        CASE WHEN order_status = 'delivered'
        THEN net_value ELSE 0 END
    ), 2) AS delivered_net_sales
FROM vw_order_analytics
GROUP BY order_month
ORDER BY order_month;
Delivered Net Sales =
CALCULATE(
    SUM(FactSales[net_value]),
    FactSales[order_status] = "delivered"
)

Delivered Gross Margin =
DIVIDE(
    [Delivered Gross Profit],
    [Delivered Net Sales]
)

Average Order Value =
DIVIDE(
    [Delivered Net Sales],
    [Delivered Orders]
)
